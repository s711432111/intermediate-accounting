# 第一章 財務報導環境與觀念架構 (Chapter 1 Source Notes)

> **教材來源**：*Intermediate Accounting: IFRS Edition (5th Edition)* by Kieso, Weygandt, Warfield
> **核心主題**：全球財務報導環境、準則制定架構（IASB）、財務報導觀念架構（三層次結構）、現金基礎轉權責基礎、迴轉分錄。

## 1. 全球金融市場與準則制定環境 (Global Financial Markets)

### 1.1 會計的本質與資本配置 (Capital Allocation)
* **會計三要素定義**：對經濟個體（Economic entities）之財務資訊進行**辨認（Identification）**、**衡量（Measurement）**與**溝通（Communication）**，以傳達給利害關係人（Interested parties）。
* **資本配置流程 (Capital Allocation Process)**：
  $$\text{財務報導 (Financial Reporting)} \longrightarrow \text{使用者 (Users: 投資人與債權人)} \longrightarrow \text{資本配置決策 (Capital Allocation)}$$
* **高品質全球會計準則之要素**：單一制定機構、一致之適用與解釋、共通揭露、高品質審計、有效之監管執行、市場參與者教育、XBRL 數位申報系統。

### 1.2 準則制定組織架構 (Standard-Setting Structure)
1. **國際證券管理機構組織 (IOSCO)**：不制定會計準則，但支持跨國發行與掛牌採用 IFRS。
2. **IFRS 基金會四層架構**：
   * **監測委員會 (Monitoring Board)**：審核與監督受託人。
   * **IFRS 基金會 (IFRS Foundation - 22位受託人)**：任命委員、提供資金、審查運作效率。
   * **國際會計準則理事會 (IASB - 14位理事)**：獨立負責制定與發布 [[IFRS 國際財務報導準則|IFRS]]。
   * **IFRS 諮詢委員會 (IFRS Advisory Council)**：提供策略建言。
   * **IFRS 解釋委員會 (IFRS Interpretations Committee - 14位委員)**：負責解釋準則適用疑義。
3. **正當程序 (Due Process)**：選定議題 $\rightarrow$ 初步觀點研究分析 (Preliminary Views) $\rightarrow$ 公開公聽會 $\rightarrow$ 發布徵求意見稿 (Exposure Draft, ED) $\rightarrow$ 評估反饋修訂 $\rightarrow$ 正式發布準則。
4. **IFRS 適用層級 (Hierarchy of IFRS)**：
   * 第一層：正式發布之 IFRS、IAS、IFRIC 及 SIC 解釋。
   * 第二層：[[財務報導觀念架構|觀念架構 (Conceptual Framework)]]。
   * 第三層：具類似觀念架構之其他準則制定機構發布之規範（如 U.S. GAAP）。

## 2. 財務報導觀念架構 (Conceptual Framework for Financial Reporting)

觀念架構共分八章，整體由**三大層次 (Three Levels)** 構成金字塔結構：

```text
▲ 第三層：實務推行概念 (The "How" - Implementation)
  ├── 基本假設 (Assumptions): 企業個體、繼續經營、貨幣單位、會計期間、權責發生
  ├── 會計原則 (Principles): 衡量原則、收入認列、費用認列、充分揭露
  └── 限制條件 (Constraint): 成本效益限制 (Cost Constraint)

▲ 第二層：承上啟下的橋樑 (Bridge between Levels 1 & 3)
  ├── 資訊品質特性 (Qualitative Characteristics): 
  │   ├── 基本品質: 攸關性 (Relevance)、忠實表述 (Faithful Representation)
  │   └── 強化品質: 可比性、可驗證性、時效性、可了解性
  └── 財務報表要素 (Elements): 資產、負債、權益、收益、費損

▲ 第一層：財務報導目標 (The "Why" - Purpose)
  └── 決策有用性 (Decision-Usefulness): 提供對現有及潛在投資人、貸與人及其他債權人有用的資源配置決策資訊
```

## 3. 財務報導之重大挑戰 (Major Challenges)

1. **政治環境下的準則制定 (Political Environment)**：
   * 會計規則具有經濟後果（Economic consequences），利益團體（企業、會計師事務所、分析師、監管機關等）經常遊說介入。IASB 必須基於嚴謹研究與經濟實質保持獨立性。
2. **期望差距 (Expectations Gap)**：
   * 社會大眾「認為」會計師/審計人員應該做到的事，與專業實際上「能」做到的客觀落差。
3. **當前新興議題**：非財務衡量指標（ESG、永續）、前瞻性資訊、軟性資產（智慧資本/品牌）、報導時效性。
4. **會計職業道德 (Ethics)**：面對短期績效壓力與法規未明確之灰色地帶時的專業誠信。
5. **國際趨同 (International Convergence)**：全球多數經濟體接軌 IFRS（包含美、中、日之互動與協調）。

## 4. 附錄專題精要 (Appendices)

### 4.1 附錄 1A：現金基礎轉權責基礎 (Cash-Basis vs. Accrual-Basis)
* **服務收入轉換**：
  $$\text{權責基礎收入} = \text{自客戶收取現金} - \text{期初應收} + \text{期末應收} + \text{期初預收} - \text{期末預收}$$
* **營業費用轉換**：
  $$\text{權責基礎費用} = \text{支付營業費用現金} + \text{期初預付} - \text{期末預付} - \text{期初應付} + \text{期末應付}$$
* 詳見專題頁面：[[cash_to_accrual_conversion|現金基礎轉權責基礎算式與工作底稿]] 與 [[cash_vs_accrual|現金基礎 vs 權責基礎之比較]]。

### 4.2 附錄 1B：迴轉分錄 (Reversing Entries)
* **核心原則**：
  1. 所有**應計項目（Accruals）**之期末調整分錄，次期初**一律作迴轉**。
  2. **遞延項目（Deferrals）**於交易發生時以「虛帳戶（費用或收入）」入帳者，次期初**作迴轉**；若原始以「實帳戶（資產或負債）」入帳者，**不作迴轉**。
  3. 折舊、攤銷、壞帳（預期信用損失）等估計項目**一律不作迴轉**。
* 詳見專題頁面：[[reversing_entries|迴轉分錄規則與經典分錄對照]]。
