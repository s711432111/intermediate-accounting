# 銀行存款調節表四象限模型與調整分錄

在會計實務中，公司帳面現金餘額 (Balance per Books) 與銀行對帳單餘額 (Balance per Bank Statement) 幾乎從未完全一致。造成差異的根源主要為**時間差異 (Time Lag)** 與**記帳錯誤 (Errors)**。編製銀行存款調節表的目的，在於求得真實的**正確現金餘額 (Correct Cash Balance)**，並作入公司帳簿。

---

## 1. 四象限調節平衡模型 (Two-Column Reconciliation)

```text
┌───────────────────────────────────────┬───────────────────────────────────────┐
│     【銀行對帳單端 Balance per Bank】  │        【公司帳面端 Balance per Books】│
├───────────────────────────────────────┼───────────────────────────────────────┤
│ 銀行對帳單期末餘額                    │ 公司帳面現金期末餘額                  │
│                                       │                                       │
│ ＋【加項】：                          │ ＋【加項】：                          │
│   • 在途存款 (Deposits in Transit)    │   • 銀行代收票據及利息 (Notes/Int)    │
│   • 銀行多扣或漏記之更正錯誤          │   • 存款利息收入 (Interest Earned)    │
│                                       │   • 公司少計收現或多記付款之錯誤      │
│                                       │                                       │
│ －【減項】：                          │ －【減項】：                          │
│   • 未兌現支票 (Outstanding Checks)   │   • 銀行代扣手續費 (Service Charges)  │
│   • 銀行少扣或多記之更正錯誤          │   • 存款不足退票 (NSF Checks)         │
│                                       │   • 公司多計收現或少記付款之錯誤      │
├───────────────────────────────────────┼───────────────────────────────────────┤
│ ＝ 調節後正確現金餘額                  │ ＝ 調節後正確現金餘額                  │
│    (Corrected Bank Balance)           │    (Corrected Book Balance)           │
└───────────────────────────────────────┴───────────────────────────────────────┘
                                   │
                           兩端金額必須嚴格相等！
```

## 2. 經典釋例：Parkwood 有限公司調節表 (Illustration 5A.1)

假設 11 月 30 日 Parkwood 公司銀行對帳單餘額為 $\$2,944.99$，公司帳面現金餘額為 $\$3,294.75$。查核發現：
1. 11/30 在途存款（公司已存入但銀行尚未入帳）：$\$565.50$。
2. 兩張未兌現支票（公司已開出但持票人尚未兌領）：#453 $\$300.00$、#457 $\$150.00$（合計 $\$450.00$）。
3. 銀行代收應收票據 $\$1,000$ 並加計利息 $\$38.00$，扣除代收手續費 $\$5.00$（淨額 $\$1,033.00$ 銀行已入帳，公司未入帳）。
4. 存款利息收入 $\$18.50$（銀行已計息，公司未入帳）。
5. 銀行借記通知書：存款不足退票 (NSF Check) $\$118.00$。
6. 銀行常規借記手續費 $\$20.00$。
7. 錯誤更正：Parkwood 公司開給廠商付款之第 443 號支票金額為 $\$122.60$（銀行正確扣款），公司帳上誤記為 $\$212.60$（多記付款支出 $\$90.00$）。

### 調節表結構演算

| 銀行對帳單端 (Bank Statement) | 金額 | 公司帳面端 (Books) | 金額 |
| :--- | :---: | :--- | :---: |
| 11/30 銀行對帳單餘額 | $\$2,944.99$ | 11/30 公司帳面現金餘額 | $\$3,294.75$ |
| 加：在途存款 | $+565.50$ | 加：銀行代收票據及利息淨額 | $+1,033.00$ |
| 減：未兌現支票 | $-450.00$ | 加：存款利息收入 | $+18.50$ |
| | | 加：第 443 號支票溢記更正 | $+90.00$ |
| | | 減：存款不足退票 (NSF Check) | $-118.00$ |
| | | 減：銀行服務手續費 | $-20.00$ |
| **調節後正確現金餘額** | **$\$3,060.49$** | **調節後正確現金餘額** | **$\$3,060.49$** |

## 3. 公司端四項必備調整分錄 (Adjusting Journal Entries)

> **黃金鐵律**：
> 1. 銀行端的項目（在途存款、未兌現支票）**公司已經入過帳**，僅是銀行尚未處理的時間差，因此**公司絕不做調整分錄**！
> 2. 只有「公司帳面端 (Books)」的所有加減項目，代表公司尚未登帳，**必須於當期期末編製調整分錄**，才能使帳上現金等於真實正確餘額 $\$3,060.49$。

### 分錄 1：記錄銀行代收票據與利息
```text
借：現金 (Cash)                                      $1,033.00
    手續費費用 (Bank Service Expense)                    $5.00
    貸：應收票據 (Notes Receivable)                               $1,000.00
        利息收入 (Interest Revenue)                                 $38.00
```

### 分錄 2：記錄存款利息收入與公司開票錯誤更正
```text
借：現金 (Cash)                                        $108.50
    貸：利息收入 (Interest Revenue)                                 $18.50
        應付帳款 (Accounts Payable) (更正多扣)                      $90.00
```

### 分錄 3：記錄存款不足退票 (恢復對客戶債權)
```text
借：應收帳款 (Accounts Receivable)                     $118.00
    貸：現金 (Cash)                                               $118.00
```

### 分錄 4：記錄銀行常規手續費
```text
借：手續費費用 (Bank Service Expense)                   $20.00
    貸：現金 (Cash)                                                $20.00
```
