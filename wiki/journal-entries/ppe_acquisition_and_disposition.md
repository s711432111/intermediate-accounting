# PP&E 取得、資本化與處分經典分錄 (Chapter 7 Journal Entries)

## 1. 包裹購買（一併購買）成本分攤 (Lump-Sum Purchase)

### 釋例條件
企業以總價 $\$300,000$ 現金包裹購入土地、土地改良物與辦公建築物。經專業估價師鑑價，三者獨立公允價值分別為：
* 土地 (Land)：$\$120,000$ (佔 30%)
* 土地改良物 (Land Improvements)：$\$40,000$ (佔 10%)
* 建築物 (Building)：$\$240,000$ (佔 60%)
* 總鑑價公允價值：$\$400,000$

### 成本分攤與會計分錄
$$\text{土地分攤成本} = \$300,000 \times \frac{\$120,000}{\$400,000} = \$90,000$$
$$\text{土地改良物分攤成本} = \$300,000 \times \frac{\$40,000}{\$400,000} = \$30,000$$
$$\text{建築物分攤成本} = \$300,000 \times \frac{\$240,000}{\$400,000} = \$180,000$$

```text
借：土地 (Land)                                     $90,000
    土地改良物 (Land Improvements)                   $30,000
    建築物 (Building)                              $180,000
    貸：現金 (Cash)                                         $300,000
```

## 2. 長期遞延付款合約（隱含重大財務組成）

### 釋例條件
企業購入高科技設備，簽發一張 3 年期、面額 $\$100,000$ 之不附息票據。同等風險之市場公平借款利率為 $8\%$。3 年期 $8\%$ 之複利現值因子為 $PVF_{3, 8\%} = 0.79383$。

### 設備入帳現值與分錄
$$\text{設備現值} = \$100,000 \times 0.79383 = \$79,383$$
$$\text{應付票據折價} = \$100,000 - \$79,383 = \$20,617$$

```text
【取得日分錄】
借：設備 (Equipment)                               $79,383
    應付票據折價 (Discount on Notes Payable)        $20,617
    貸：應付票據 (Notes Payable)                            $100,000

【第 1 年底利息攤銷分錄 ($79,383 \times 8\% = $6,351)】
借：利息費用 (Interest Expense)                     $6,351
    貸：應付票據折價 (Discount on Notes Payable)              $6,351
```

## 3. IAS 23 借款成本資本化分錄

### 釋例條件
企業自建倉庫，年度累積支出加權平均數 (WAAE) 為 $\$800,000$。
* 專案借款：$\$500,000$，年利率 $10\%$，年度產生利息 $\$50,000$；建造期間未動用借款產生暫時性利息收益 $\$3,000$。
* 超額 WAAE：$\$800,000 - \$500,000 = \$300,000$，企業一般借款加權平均利率為 $12\%$，超額可避免利息為 $\$36,000$。
* 企業年度實際總利息支出為 $\$120,000$。

### 利息資本化計算
$$\text{可避免利息} = (\$50,000 - \$3,000) + \$36,000 = \$47,000 + \$36,000 = \$83,000$$
因為可避免利息 $\$83,000 < \text{實際利息} \$120,000$，故全額資本化 $\$83,000$，剩餘 $\$37,000$ 認列為當期利息費用。

```text
借：在建工程－倉庫 (Construction in Process - Warehouse)   $83,000
    利息費用 (Interest Expense)                           $37,000
    貸：現金／應付利息 (Cash / Interest Payable)                  $120,000
```

## 4. IAS 16 非貨幣性資產交換分錄

### 釋例條件
甲公司以舊機器換入乙公司之新設備，並另支付現金 $\$5,000$。
* 舊機器原始成本 $\$50,000$，累計折舊 $\$28,000$（帳面價值 $\$22,000$）。
* 舊機器於交換日之公允價值為 $\$26,000$。
* （利得情況：公允價值 $\$26,000 - \text{帳面價值} \$22,000 = \$4,000$ 利得）

### 情境 A：具備商業實質 (Has Commercial Substance)
> 利得立即認列，換入新設備成本 = 換出公允價值 $\$26,000 + \text{支付補價} \$5,000 = \$31,000$。
```text
借：設備－新 (Equipment - New)                     $31,000
    累計折舊－舊設備 (Accumulated Depreciation)      $28,000
    貸：設備－舊 (Equipment - Old)                          $50,000
        現金 (Cash)                                          $5,000
        處分資產利得 (Gain on Disposal of Equipment - P&L)    $4,000
```

### 情境 B：不具備商業實質 (Lacks Commercial Substance)
> 利益不得認列（全額遞延），新設備以換出帳面價值 $\$22,000 + \text{支付補價} \$5,000 = \$27,000$ 入帳。
```text
借：設備－新 (Equipment - New)                     $27,000
    累計折舊－舊設備 (Accumulated Depreciation)      $28,000
    貸：設備－舊 (Equipment - Old)                          $50,000
        現金 (Cash)                                          $5,000
```

## 5. IAS 20 政府補助款分錄 (Government Grants)

企業購置 $\$500,000$ 環保設備，政府補助 $\$100,000$ 現金。

### 方式一：遞延收益法 (Deferred Grant Income)
```text
借：設備 (Equipment)                              $500,000
    貸：現金 (Cash)                                         $500,000

借：現金 (Cash)                                   $100,000
    貸：遞延政府補助利益 (Deferred Grant Revenue)           $100,000
（後續按設備耐用年限逐期攤銷轉為其他利益）
```

### 方式二：資產成本扣減法 (Net Deduction Approach)
```text
借：設備 (Equipment)                              $400,000
    貸：現金 (Cash - 淨支付)                                $400,000
（直接以淨額 $400,000 認列設備，後續按 $400,000 提列折舊）
```

## 6. 資產處分與非自願轉換 (Disposal & Involuntary Conversion)

### 6.1 一般報廢或出售
```text
【步驟一：補提當年度處分前折舊】
借：折舊費用 (Depreciation Expense)                $3,000
    貸：累計折舊 (Accumulated Depreciation)                  $3,000

【步驟二：除列資產並認列處分損益】
借：現金 (Cash - 出售淨得款)                       $18,000
    累計折舊 (Accumulated Depreciation)           $42,000
    處分資產損失 (Loss on Disposal of PP&E - P&L)   $5,000
    貸：設備 (Equipment - 原始成本)                          $65,000
```

### 6.2 火災等非自願轉換 (Involuntary Conversion)
工廠因火災全毀，成本 $\$200,000$，累計折舊 $\$120,000$（帳面價值 $\$80,000$），獲得保險公司理賠現金 $\$110,000$：
```text
借：現金／應收保險理賠款 (Cash / Insurance Receivable)   $110,000
    累計折舊 (Accumulated Depreciation)                 $120,000
    貸：廠房 (Plant Building)                                 $200,000
        火災保險處分利得 (Gain on Involuntary Conversion - P&L) $30,000
```
